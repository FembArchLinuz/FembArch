## What is FembArch?
FembArch is an Arch-based distro made for everyone not just femboys.
FembArch is still in development so you might experience some big updates.
Although FembArch is not as stable as Arch Linux or CachyOS, Manjaro but its still a linux distro, right?
## Package Manager
The package manager for FembArch is fembpkg which is literally just a wrapper for pacman.
'How do i use fembpkg?'

```bash
fembpkg femb-get <package>
fembpkg femb-search <package>
fembpkg femb-remove <package>
```

Thats all for the Package Manager (for now.)

## Customization Tool FembArcher
FembArcher is a customization tool made for linux distros like fedora ubuntu etc
A quick warning to non-arch users, FembArcher uses pacman package manager not dnf or apt package manager so you might need to change those lines.
To download & run FembArcher you must do this:

```bash
git clone https://github.com/FembArchLinuz/FembArcher.git
cd FembArcher
chmod +x Fembarcher.sh
./Fembarcher.sh
```
