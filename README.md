FembArch Linux is a Arch-Based Linux distro that is Femboy/Anime oriented.

# Downloading the repo

bash `` 
git clone https://github.com/FembArchLinuz/FembArch
cd ~/FembArch
``
Then do whatever you want with it, make your own versions, whatever.
